光譜干涉實驗室（歐幾里得視角）

兩組三維駐波「晶格」互相轉一個小角度疊加，紅、綠、藍三色的波數不同（色散），各自產生不同的干涉圖樣。 只保留建設性干涉的亮點畫成 3D 點雲：三色都亮的地方混成白色，只有部分顏色亮的地方就出現彩色邊緣。 拖曳畫面可旋轉視角，滾輪可縮放。

👁 歐幾里得視角（有理數視線）

當視線斜率 tan θ = p/q 為簡單有理數時，視線與晶格排列共振，形成最強烈的「視覺走廊」與色散效應。

微小角度差異產生大尺度波形

沿 x 軸（y = z = 0）的三色強度剖面 I(x)，與目前參數同步
紅 I_R綠 I_G藍 I_B亮度門檻 0.25
觀察指南

白色中心：三原色都發生建設性干涉的區域。
彩色邊緣：切換到有理數比例視角時，觀察「視覺走廊」兩側的紅藍分離現象。
色散 = 1.0 時三色波數相同，點雲只剩黑白灰；把色散調大，紅（波數小）與藍（波數大）的亮紋位置錯開，彩色邊緣就變寬。 左圖剖面裡三條曲線的峰值位置錯開多少，就是彩色邊緣有多寬。

物理重點：每一色都是兩組三維駐波的疊加：A = cos(kx)cos(ky)cos(kz)、晶格 B 是把座標繞 z 軸轉 θ 後的同一個波， 強度 I = (A + B)² / 4（振幅相加後平方——干涉的本質是振幅相加、不是強度相加）。 三色波數 k_R = K/√D、k_G = K、k_B = K·√D：紅光波長長、波數小；藍光波長短、波數大。 兩組晶格只差一點角度，就像疊紗的疊紋（莫列波紋），會拍出比原本週期大得多的圖樣。 點雲用蒙地卡羅取樣：隨機撒點，平均亮度 > 0.25 才有機會留下、越亮越容易留下，所以點越密的地方越亮。
