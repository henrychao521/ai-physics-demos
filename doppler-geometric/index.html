都卜勒效應與等比級數（波前等差數列・反射牆頻率等比數列）

都卜勒效應不只是頻率公式，更蘊含了數學數列之美：單向移動波源的發出與接收時刻形成等差數列；而在相對逼近的雙反射牆之間，聲波的頻率、波長、兩牆距離與來回時間則構成精巧的等比數列與收斂的無窮等比級數。

時空圖（Spacetime Diagram） 橫軸 x、縱軸 t 往下；聲脈衝鋸齒世界線隨反射越變越密

頻率成長折線圖（半對數座標） 精確等比數列在對數圖上成直線 vs 線性近似

物理重點：等差數列（每個波峰間隔被壓縮成同一個比例）與等比數列（每次反射乘同一個公比）的差別；無窮多次反射卻在有限時間內完成＝收斂的無窮等比級數。

⚖️ 精確與近似（誠實的物理模型）

  • 精確（在「介質靜止、一維、牆等速、完全反射」的前提下）：
    • 模式 A：發出時刻 tᵢ 與抵達時刻 tᵢ' 兩組嚴格排成等差數列，觀察頻率 f' = f / (1 − v/c) 為精確解。
    • 模式 B：每次反射後的頻率 fₙ = f₀ · kⁿ、兩牆距離 Dₙ = D₀ / kⁿ、每趟來回時間 Δtₙ 皆為嚴格等比數列。
    • 無窮等比級數和 Σ Δtₙ = D₀ / u 嚴格等於移動牆走完初始距離 D₀ 的時間。
    • 守恆不變量：兩牆之間的總波數 N_waves = Dₙ / λₙ = Dₙ · fₙ / c = D₀ · f₀ / c 恆定不變（即 Dₙ · fₙ 守恆）。
  • 近似：
    • 當牆速遠小於聲速（u ≪ c）時，公比 k = (c+u)/(c−u) = (1+u/c)/(1−u/c) ≈ 1 + 2u/c。
    • 因此頻率可線性近似為 fₙ ≈ f₀(1 + 2nu/c)。但此近似只在 n·u/c ≪ 1 時準確；隨著反射次數 n 增加，誤差會越來越大（可參見上方數據表格的相對誤差）。
    • 真實世界中，牆壁不可能達成 100% 完全反射，聲波在空氣中傳播亦會發散與黏滯吸收衰減。
  • 對光的推廣：
    • 鏡子以 u 移動時，狹義相對論中光反射後的頻率公比為 (1+β)/(1−β)（其中 β = u/c），與此處聲波的 (c+u)/(c−u) 形式完全一樣。

🚗 生活中的應用：一次反射的都卜勒技術

警用雷達測速槍與醫學都卜勒超音波（測量血管紅血球流速）在工程上只利用「一次反射」（n = 1）：
目標物反射後的訊號頻率為 f₁ = f₀ (c+u) / (c−u)。
在目標速率遠小於波速（u ≪ c）的前提下，接收器將回波與發射波混頻產生拍頻（Beat frequency）測量頻率差：
Δf = f₁ − f₀ = f₀ · [ (c+u)/(c−u) − 1 ] = f₀ · 2u/(c−u) ≈ (2u/c) · f₀
因此儀器只要測出頻率差 Δf，就能瞬間反推出目標移動速度 u ≈ c · Δf / (2f₀)。
