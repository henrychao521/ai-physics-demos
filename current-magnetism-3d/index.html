電流的磁效應 3D ｜ 安培右手定則・磁力線與指南針

透過立體空間視角探索電流的磁效應。觀察直導線周圍的同心圓磁場、圓線圈中心集中的磁力線，以及螺線管內部接近均勻、外如磁鐵的偶極磁場。本頁 3D 空間磁場由必歐-沙伐定律數值疊加計算，可自由拖曳旋轉、縮放視角並對照理論公式。

右手定則：握住導線，拇指＝電流方向，四指繞向＝磁場方向。
物理重點： 1820 年厄斯特發現電流生磁。直導線周圍磁場呈同心圓環繞，大小 B = μ₀I/(2πr)，隨距離成反比（B ∝ 1/r）。 圓線圈將導線彎成環狀，各段微小電流在中心處產生的磁場方向一致疊加，中心 B = μ₀I/(2R)，比同半徑直導線強 π 倍。 螺線管由多圈環形導線串聯成螺旋，管內磁力線緊密平行，內部近乎均勻 B = μ₀nI（n＝N/L 為匝密度），管外磁場散開回繞，外部磁力線分佈和棒狀磁鐵相似。 安培右手定則兩種握法：直導線以拇指順電流、四指繞向為磁場；線圈與螺線管則以四指彎曲順著環繞電流、伸直的拇指即指向內部磁場方向（N 極端）。指南針在磁場中受力矩旋轉，平衡時其 N 極（紅色）恆指向磁場 B 的切線方向。本 3D 模擬的空間磁場大小皆由必歐-沙伐定律對有限長導線微元嚴格數值疊加計算，而非示意簡化繪製。
